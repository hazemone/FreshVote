# Running the FreshVote Primary Evaluation on Linux

This package contains the **isolated FreshVote implementation** and the frozen held-out calibration record. It does not modify the uploaded `consensus-cliff-main` baseline. The primary evaluation uses 3,840 runs: four policies, 24 communication-stress conditions, and 40 test seed pairs. The test seeds are 21–60 and are deliberately disjoint from the calibration seeds 1–20.

> **Do not use the smoke-test or calibration outputs as paper results.** Only the full primary evaluation generated by the command below is eligible for the paper’s main tables and figures.

## 1. Prepare the environment

Open a terminal in the extracted `freshvote` folder. The scripts require Python 3.10+ and NumPy. A virtual environment is recommended.

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install --upgrade pip
python3 -m pip install numpy pytest
cd code
export OMP_NUM_THREADS=1
export OPENBLAS_NUM_THREADS=1
export MKL_NUM_THREADS=1
pytest -q
```

All tests must pass before beginning the full experiment. The expected result in the current package is `40 passed`.

## 2. Run a four-job sanity check

This command checks that your laptop can execute the evaluation runner and writes a clearly labelled pilot dataset. It is not a scientific result.

```bash
rm -rf ../results/evaluation_pilot_local
python3 run_freshvote_evaluation.py \
  --seed-count 1 --workers 2 --agents 20 --steps 120 --max-jobs 4 \
  --output-dir ../results/evaluation_pilot_local
```

## 3. Execute the frozen full primary matrix

With a 32-core, 32 GB Linux laptop, begin with 24 worker processes so the desktop remains responsive. Keep the laptop connected to power and prevent sleep. The exact duration depends on processor performance; allow an unattended overnight run if necessary.

```bash
rm -rf ../results/evaluation_full_local
python3 run_freshvote_evaluation.py \
  --workers 24 \
  --output-dir ../results/evaluation_full_local \
  2>&1 | tee ../results/evaluation_full_local.log
```

A successful completion writes both `evaluation_manifest.json` and `evaluation_runs.csv` under `results/evaluation_full_local/` and prints:

```text
Completed 3840 of 3840 planned evaluation runs
```

The full run must keep the defaults of 100 agents, 3,000 ticks, evaluation seeds 21–60, and zero `--max-jobs`. Do not change the frozen policy values: hard TTL `9`, fixed-decay rate `0.35`, and FreshVote \(\kappa=1.5\).

```bash
cd ..

```

## 5. Troubleshooting

| Symptom | Action |
|---|---|
| `pytest: command not found` | Activate `.venv` and run `python3 -m pip install pytest`. |
| `ModuleNotFoundError: numpy` | Activate `.venv` and run `python3 -m pip install numpy`. |
| Laptop becomes unresponsive | Stop with `Ctrl+C`, reduce `--workers 24` to `--workers 16`, delete the partial output folder, and restart. |
| Process interrupted | The current runner writes the final CSV after all jobs finish; delete the incomplete output directory and restart so every result is generated in one controlled batch. |
| Results have fewer than 3,840 rows | Treat them as incomplete and do not use them. Upload the log if you need help diagnosing the interruption. |
